# Built for developers. Governed as a platform.

KongAir is a fictional airline used to demonstrate API delivery with Kong
Konnect. Explore public flight and destination APIs, or request application
access to the protected booking and customer APIs.

## How the example is managed

The Platform Team owns shared infrastructure, Portals, access governance, and
production Gateway changes. Service teams own their Catalog APIs, specifications,
publications, and development Gateway configuration. Reviewed declarative
configuration and automated workflows connect the two.

## Read the implementation

- [Konnect Reference Platform](https://developer.konghq.com/konnect-reference-platform/)
- [KongAirlines example repositories](https://github.com/KongAirlines)

This is an educational example with fictional data, not a production airline
offering. No availability or service-level commitment is implied.
