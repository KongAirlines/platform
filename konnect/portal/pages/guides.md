# Build with KongAir

Follow these guides to understand the API contracts, request the right access,
and keep development and production credentials separate.

## Start here

- [Getting started](/guides/getting-started): choose an API and find its contract.
- [Application access](/guides/application-access): register an application,
  request approval, and use a Portal-issued API key.
- [Environments and versions](/guides/environments): understand which contract
  you are reading and where your credentials work.

## Before you integrate

KongAir is a reference implementation, not a commercial airline service.
Use fictional data and never submit real passenger or payment information.
